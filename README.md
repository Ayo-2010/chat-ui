# Chatter

A modern messenger front end with a fake bot that answers in every conversation.

## Features

- Four switchable conversations in a sidebar, each with an avatar letter and a live preview
- Message bubbles for you and the other side with timestamps and day dividers
- Send with the button or Enter, then watch an animated three dot typing indicator
- A rotating pool of canned bot replies that is unique to each conversation
- Quick emoji bar that inserts any emoji straight into the input
- Dark and light themes toggled with a data attribute on the root element
- Messages and the active conversation persist in localStorage
- Online status dot with a soft pulse animation

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.
